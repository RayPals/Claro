# Claro Lessons

These are small lesson programs for the first hour of learning Claro.

Recommended order:

1. `01_hello.claro` - show text with `SAY`
2. `02_ask_name.claro` - ask a question with `ASK`
3. `03_variables.claro` - remember information with `SET`
4. `04_math.claro` - add values
5. `05_if_else.claro` - make choices
6. `06_loops.claro` - repeat actions
7. `07_lists.claro` - store more than one value
8. `08_functions.claro` - make reusable actions with `TEACH`
9. `09_files.claro` - save and read a file
10. `10_final_quiz.claro` - combine input and choices

Run one lesson:

```bash
./claro lessons/01_hello.claro
```

On Windows:

```powershell
.\claro.exe lessons\01_hello.claro
```
