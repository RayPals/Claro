# Claro Errors

Claro tries to report mistakes in beginner-friendly language.

Examples:

```text
I do not know the command "PRNT". Did you mean "SAY"?
```

```text
SET needs TO.
Try:
SET name TO "Alex"
```

```text
IF block opened here is missing ENDIF
```

```text
I do not know the variable "socre" yet. Did you mean "score"?
```

For safer learning, run this before running a new program:

```bash
./claro check my_program.claro
```
