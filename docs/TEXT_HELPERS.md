# Text Helpers

Claro includes small text commands for beginner scripts.

```claro
TEXT UPPER "hello" AS loud
TEXT LOWER "LOUD" AS quiet
TEXT TRIM "  neat  " AS clean
TEXT LENGTH clean AS size
TEXT CONTAINS "hello world" NEEDLE "world" AS hasWord
TEXT STARTS "Claro language" WITH "Claro" AS startsRight
TEXT ENDS "Claro language" WITH "age" AS endsRight
TEXT REPLACE "Hello world" FROM "world" TO "Claro" AS changed
```
