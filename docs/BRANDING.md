# Claro Branding

Claro's official logo is included at:

```text
assets/Claro_Logo.jpg
```

The logo is a blue-green puzzle-piece mark with a bold **C** in the center.

Use it in README files, release pages, classroom handouts, and future IDE/tooling screens where branding is helpful.

For beginner-facing materials, keep the logo large enough to recognize and do not place it over busy backgrounds.
